# CESO Community Extension Services System - User Manual

## System Overview
The CESO Portal is a web-based platform that manages community outreach programs, tracks participant engagement, and analyzes feedback using AI-powered sentiment analysis. The system supports multiple user roles with tailored dashboards and functionalities.

## User Roles & Access

### 1. IT Administrator
**Login:** Use admin credentials provided by system administrator
**Main Functions:**
- Manage user accounts (create, edit, archive)
- Bulk import users via CSV
- Monitor system performance
- Access all system modules

### 2. CESO Staff
**Login:** Use CESO role credentials
**Main Functions:**
- Create and manage outreach activities
- View sentiment analysis results
- Generate reports and analytics
- Manage announcements and website content

### 3. Community Users (Students, Faculty, Staff)
**Login:** Register or use existing account
**Main Functions:**
- Browse available activities
- Join activities using entry codes
- Submit feedback and ratings
- View participation history
- Access certificates

## Getting Started

### Registration & Login
1. Visit the CESO Portal website
2. Click "Register" for new users or "Login" for existing accounts
3. Fill in required information (name, email, role)
4. Verify email if required
5. Login with username/email and password

### Password Management
- Click "Forgot Password" on login page
- Enter registered email
- Follow reset instructions sent to email
- Create strong password (8+ characters, mix of letters/numbers/symbols)

## Key Features Guide

### For Community Users

#### Browsing Activities
1. Login to your account
2. Navigate to "Activities" section
3. View available programs with details (date, venue, description)
4. Use search and filter options

#### Joining Activities
1. Find desired activity
2. Click "Join Activity"
3. Enter the 6-character entry code provided by organizers
4. Confirm participation
5. Receive confirmation email

#### Submitting Feedback
1. Go to "My Participation" section
2. Select completed activity
3. Rate activity (1-5 stars)
4. Write detailed feedback
5. Submit feedback
6. View sentiment analysis results (if available)

#### Viewing Certificates
1. Access "My Certificates" section
2. Download participation certificates
3. Share certificates on social media

### For CESO Staff

#### Creating Activities
1. Login as CESO staff
2. Go to "Activities" → "Create Activity"
3. Fill in activity details:
   - Title, venue, dates, description
   - Entry code (auto-generated)
4. Select participants (faculty, students, staff, community)
5. Add attachments if needed
6. Publish activity

#### Managing Participants
1. In activity details, view participant list
2. Add/remove participants manually
3. Send invitations via email
4. Track participation status

#### Viewing Analytics
1. Access "Dashboard" for overview
2. View sentiment analysis charts
3. Generate reports on participation and feedback
4. Export data for further analysis

### For IT Administrators

#### User Management
1. Go to "User Management" section
2. Create new users individually or bulk import
3. Edit user roles and permissions
4. Archive inactive users
5. Reset user passwords

#### System Monitoring
1. Check system logs and performance
2. Monitor API usage and response times
3. View error reports and system health

## Sentiment Analysis Feature

### How It Works
- System analyzes feedback using AI (OpenAI GPT models)
- Classifies sentiment as Positive, Neutral, or Negative
- Provides effectiveness scores and recommendations
- Generates role-specific improvement suggestions

### Viewing Results
1. CESO staff can view analysis in activity details
2. Community users see basic sentiment labels
3. Detailed explanations available via "Explain Sentiment" button

## Common Tasks

### Updating Profile
1. Click profile icon/name in top navigation
2. Select "Profile Settings"
3. Update personal information
4. Change password
5. Save changes

### Viewing Announcements
1. Check "Announcements" section regularly
2. Read updates from CESO staff
3. Important notices appear on dashboard

### Troubleshooting

#### Login Issues
- Check email and password spelling
- Use "Forgot Password" if needed
- Clear browser cache and cookies
- Try different browser or device

#### Activity Not Showing
- Check if activity is published
- Verify correct entry code
- Contact CESO staff for assistance

#### Feedback Not Submitting
- Ensure all required fields are filled
- Check internet connection
- Try refreshing the page
- Contact support if issues persist

#### System Slow/Lagging
- Check internet connection speed
- Close unnecessary browser tabs
- Clear browser cache
- Try during off-peak hours
