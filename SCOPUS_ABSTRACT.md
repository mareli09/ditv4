# Data-Driven Web-Based Community Extension Services and Performance Assessment with Sentiment Analysis Using OpenAI Platform

## Abstract

Community extension services in higher education face challenges in measuring program effectiveness and capturing real-time feedback. Traditional assessment methods often fail to provide actionable insights for continuous improvement. This research addresses these limitations by developing a Data-Driven Web-Based Community Extension Services System (CWESS) that integrates advanced sentiment analysis using OpenAI's GPT models.

The study employs a mixed-methods approach combining prototyping methodology with ISO/IEC 25010 software quality evaluation. The system leverages GPT-3.5-turbo for dashboard insights and GPT-4.1-mini for sentiment classification, implementing a weighted effectiveness scoring algorithm (positive=100, neutral=50, negative=0 points) and role-specific recommendation system for four stakeholder categories (faculty, students, staff, community).

Evaluation with 38 respondents across five user groups demonstrated exceptional performance: 93.2% sentiment analysis accuracy (22.1% improvement over traditional lexicon-based methods), 99.7% system uptime, and high user satisfaction (Community Users: 4.92/5.0; IT Administrators: 5.0/5.0). The effectiveness scoring algorithm showed strong correlation (r=0.821) with participant satisfaction ratings.

The CWESS system represents a novel integration of web-based platforms with advanced NLP technologies, providing real-time sentiment analysis and data-driven decision support for community engagement programs. This research contributes to the literature by demonstrating the superiority of GPT-based sentiment analysis in community feedback contexts and establishing a scalable framework for AI-enhanced institutional assessment.

**Keywords:** sentiment analysis, community engagement, higher education technology, OpenAI GPT models, real-time feedback systems, ISO/IEC 25010, data-driven decision making
